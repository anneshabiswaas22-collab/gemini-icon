# Contributing

Welcome. Please read \`README.md\`, \`docs/PROJECT_CONTEXT.md\`, and \`docs/DEVELOPER_HANDOFF.md\` first.

1. Open an issue explaining the defect/feature, expected media behavior, and a reproducible test case.
2. Make a focused branch from \`main\` and commit clear changes.
3. Include tests; run \`python -m unittest discover -s tests -v\` before submitting.
4. Open a pull request describing the algorithm, performance/quality tradeoffs, and before/after results from **authorized** media.
5. Never commit passwords, private source videos, personal chat exports, or large binary outputs.
6. Respect original media attribution and applicable rights. Do not claim perfect pixel recovery without visual evidence.

**License status:** The owner has not selected a license yet. Public visibility alone is not an open-source grant. Please discuss licensing in an issue before redistributing the code beyond applicable permissions.
